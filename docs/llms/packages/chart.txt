# @rokkit/chart

D3-powered composable chart components for Svelte 5. High-level chart components, a low-level declarative geom API, faceted and animated plots, inline sparklines, and a reactive crossfilter system for linked views.

## Install

```bash
npm install @rokkit/chart
```

## Annotating the plane — Rule, Region, Hull, Contour

Four geoms describe the metric plane rather than a row. SVG paints in document order, so put
them BEFORE the marks they sit behind.

```svelte
<PlotChart data={components} xDomain={[0, 1]} yDomain={[0, 1]} legend tooltip>
  <Plot.Region name="pain" points={[[0, 0], [0.5, 0], [0, 0.5]]} label="Zone of pain" />
  <Plot.Region name="uselessness" points={[[1, 1], [0.5, 1], [1, 0.5]]} label="Zone of uselessness" />
  <Plot.Hull x="instability" y="abstractness" color="package" />
  <Plot.Contour x="instability" y="abstractness" bandwidth={28} />
  <Plot.Rule slope={-1} intercept={1} label="main sequence" />
  <Plot.Point x="instability" y="abstractness" color="package" size="loc" />
</PlotChart>
```

| Geom | Props | Notes |
|------|-------|-------|
| `Rule` | `x`, `y` (value or array), `slope`, `intercept` (default 0), `label`, `color`, `dash`, `strokeWidth` | A sloped line is clipped in data space, so it stays inside the plot at any zoom; ignored on band axes. Its label sits at the midpoint, rotated along it. `data-plot-rule="x"\|"y"\|"slope"` |
| `Region` | `x`, `y` (`[lo, hi]`, a `null` end runs to the axis edge), `points` (`[[x, y], …]`, wins), `name`, `label`, `labelAt`, `fill`, `alpha`, `stroke` | Reads no data, registers no geom, never moves the scales — fix the domain when the region defines the frame. Clipped to the plot. A band category covers its whole band. `data-plot-region="<name>"`; `--chart-region-{fill,opacity,label-color,label-size,label-opacity}` |
| `Hull` | `x`, `y`, `fill` / `color` (group field + its palette colour), `padding` (px, default 10), `alpha` (default 0.15), `label` | Hull computed in screen space. A 1-member group is a dot, a 2-member group a capsule. `data-plot-hull="<group>"` |
| `Contour` | `x`, `y`, `fill` / `color` (group), `bandwidth` (px, default 20), `thresholds` (default 8), `filled`, `alpha` | d3-contour `contourDensity`. Level 0 is the outermost ring; filled bands ramp opacity toward `alpha` at the core. Clipped to the plot. `data-plot-contour`, `data-plot-contour-level`; `--chart-contour-{color,width,opacity}` |

## Architecture analysis recipes

The learn site's chart explorer composes those geoms over metrics measured from rokkit itself
(`apps/learn/scripts/build-architecture-metrics.mjs`). The zones and thresholds belong to the
analysis, not the package — each recipe is ordinary geoms:

| Recipe | x × y | Built from |
|--------|-------|------------|
| Main sequence (Martin) | instability `Ce/(Ca+Ce)` × abstractness | `Region` polygons for the zones of pain and uselessness, `Rule slope={-1} intercept={1}`, `Hull` per package, `Contour` |
| Hotspots | complexity × churn | `Region x={[p95, null]} y={[p95, null]}` |
| Complexity × coverage | complexity × statement coverage | `Region` for complex-and-under-tested, `Rule y={0.8}` |
| Fan-in × fan-out | fan-out × fan-in | `Region` for hubs and for reaches-everywhere |
| God modules | complexity × fan-out | `Region` past p95 on both |

Use percentiles of the codebase itself for thresholds, and the 95th rather than the 90th: these
metrics are heavy-tailed, and a p90 fan-in of 3 shades most of the plot.

## Continuous Color Scales

For heatmaps, hexbins, and other density visualizations, use sequential or diverging color scales:

```javascript
import { buildSequentialScale, buildDivergingScale } from '@rokkit/chart'

// Sequential: 0→100 mapped to a blue gradient
const seq = buildSequentialScale(data, 'value', { colorScheme: 'blues' })

// Diverging: -10→0→10 mapped to red-white-blue
const div = buildDivergingScale(data, 'delta', { colorScheme: 'rdbu', colorMidpoint: 0 })
```

Available sequential schemes: `blues`, `greens`, `oranges`, `purples`, `reds`, `viridis`, `inferno`, `magma`, `plasma`, `cividis`, `turbo`, `warm`, `cool`, and more.

Available diverging schemes: `rdbu`, `rdylbu`, `rdylgn`, `brbg`, `piyg`, `prgn`, `puor`, `spectral`.

Configure via `PlotSpec`:

```javascript
const spec = {
  data, x: 'day', y: 'hour', color: 'value',
  colorScale: 'sequential',    // 'categorical' | 'sequential' | 'diverging'
  colorScheme: 'viridis',
  geoms: [{ type: 'heatmap' }],
  legend: true
}
```

## Plot State (advanced)

`PlotState` is the reactive state `PlotChart` publishes on the `'plot-state'` context. It is a
composition of job classes, each exposed as a member:

| Member | Job |
|--------|-----|
| `config` | every input; `update(config)` re-applies them (omitted overrides — margin, domains, orientation, sort, axis origin — reset; everything else is kept) |
| `geoms` | mounted geoms, `data(id)` for a geom's rows |
| `frame` | margin, inner width/height |
| `channelState` | effective channels and field getters |
| `orientationState` | orientation, flip, `place(u, v)` |
| `interactionState` | hover, selection, zoom |
| `scales` | `x`, `y`, `band`, `value` |
| `aesthetics` | `colors`, `patterns`, `symbols`, continuous colour |
| `axes` | `xAxisY`, `yAxisX` |

The flat getters geoms have always read (`xScale`, `colors`, `place`, `innerWidth`, …) remain,
as delegations.

```javascript
import { PlotState } from '@rokkit/chart'
```

## Geom Aesthetics (fill / color / alpha / position / group)

Every geom maps to data via ggplot-aligned aesthetic channels (field names), resolved through one
shared categorical palette. A geom is a declarative component backed by a per-geom `GeomState`
class: set props, the shared `PlotState` context supplies scales/colors, and the geom renders the
computed marks (tagged `data-plot-geom` / `data-plot-element`).

| Channel | Meaning |
|---------|---------|
| `x`, `y` | position (field) |
| `color` | outline / line / point-stroke (field) |
| `fill` | interior (field); falls back to `color` |
| `alpha` | fixed opacity 0–1 (number); per-geom preset default via `preset.opacity[type]` |
| `size` | mark size (field) — Point |
| `symbol` | shape (field) — Point / Line markers |
| `pattern` | texture fill (field) |
| `group` | sub-series (field); defaults to `fill ?? color` |
| `position` | Bar/Area arrangement: `stack` \| `dodge` \| `fill` (100%) \| `identity` |

Fill/color fallback: color-only → fill & stroke from color; fill-only → both from fill; both →
interior from fill, outline from color. `options.stack: true` is a deprecated alias for
`position="stack"`. `Plot.Root` accepts `color`/`fill` channel defaults that geoms inherit.
