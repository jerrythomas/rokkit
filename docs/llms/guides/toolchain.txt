# Toolchain

`@rokkit/cli` is the canonical way to set up a Rokkit project,
upgrade between versions, and generate scaffolding. Manual setup
works but tends to drift — the CLI keeps the moving parts
(UnoCSS config, theme imports, `data-style` attribute) in sync.

## init — bootstrap a project

```bash
npx @rokkit/cli@latest init
```

The init command is interactive. It prompts for:

- **Colour palette** — `default` (orange / pink / sky),
  `vibrant` (blue / purple / sky), `seaweed` (sky / green /
  blue), or `custom` (you pick the Tailwind palette names per
  role).
- **Icon collection** — Rokkit's built-in collection, or
  Rokkit plus a custom collection JSON.
- **Theme styles** (multi-select) — `rokkit`, `minimal`,
  `material`, `frosted`, `zen-sumi`. Pick one or more; the CLI
  sets up the import + the `data-style` attribute for the first.
- **Theme switching** — `system` (prefers-color-scheme),
  `manual` (light / dark toggle), or `full` (both light/dark
  and style variants).

Files written: `rokkit.config.js`, `uno.config.js`,
`src/app.css`, `src/app.html`.

## doctor — verify & fix

```bash
npx @rokkit/cli@latest doctor
```

Walks the project and reports drift between what `init` would
produce and what's currently committed — missing UnoCSS preset,
unfilled `data-style` attribute, missing theme imports, etc.
`--fix` re-applies the corrections in place.

## upgrade — between Rokkit versions

```bash
npx @rokkit/cli@latest upgrade
```

Reads your `rokkit.config.js`, checks the registry for newer
`@rokkit/*` packages, and bumps your `package.json` in lockstep.
Reports breaking-change notes inline so you know what to
hand-merge.

## skin — manage named skins

```bash
npx @rokkit/cli@latest skin list                 # list skins defined in rokkit.config.js
npx @rokkit/cli@latest skin create --name ocean  # add a new skin entry
```

`skin create` writes a new named skin (token roles → palette
names) into the `skins` block of `rokkit.config.js`; apply it
with `<body data-skin="ocean">`.

## theme — manage theme styles

```bash
npx @rokkit/cli@latest theme list               # list built-in + custom themes
npx @rokkit/cli@latest theme create --name corp # scaffold a new CSS theme stub
```

`theme create` writes `src/themes/<name>.css` — a stub with all
the data-attribute selectors components target, pre-filled with
comments. You override the visual recipe (border-radius, shadows,
surface treatments); the data-attribute structure stays the same.

## skills — install AI skill guides

```bash
npx @rokkit/cli@latest skills list          # show available bundled skills
npx @rokkit/cli@latest skills add           # interactive picker
npx @rokkit/cli@latest skills add --all     # install all skills
```

Copies bundled SKILL.md guides into `.claude/skills/` for use with
Claude Code and compatible AI assistants. Available since v1.1.13.

## agents — install review agents

```bash
npx @rokkit/cli@latest agents list          # show available bundled agents
npx @rokkit/cli@latest agents add           # interactive picker
npx @rokkit/cli@latest agents add --all     # install all agents
```

Copies bundled review agents into `.claude/agents/` — `rokkit-styles-reviewer`
(config/token wiring) and `rokkit-components-reviewer` (customization tiers,
custom icons, typography). Available since v1.3.7.

## Editor / build integration

- **UnoCSS preset** — `@rokkit/unocss` adds Rokkit's semantic
  token shortcuts (`bg-paper-soft`, `text-ink-mute`, etc.) plus the
  preflight CSS variables.
- **`skinnable` action** (`@rokkit/actions`, not a build tool) —
  applies named-token colors as inline CSS custom properties on
  an element, for runtime / dynamic skins that aren't pre-baked.
  It does **not** set `data-style` (that's the `themable` action
  + `vibe` store).

## Icon collections

`@rokkit/icons` ships a curated default collection
(`@iconify-json/glyph`). Swap it in your unocss config:

```js
import { presetIcons } from '@unocss/preset-icons'

export default {
  presets: [
    presetIcons({
      collections: {
        glyph: () => import('@iconify-json/mdi/icons.json').then(m => m.default)
      }
    })
  ]
}
```
