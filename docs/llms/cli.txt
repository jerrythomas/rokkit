# Rokkit CLI

> Command-line tools for setting up and validating Rokkit projects

Package: `@rokkit/cli`

## Usage

Run without installing:
```bash
npx @rokkit/cli@latest <command>
```

Or install globally:
```bash
npm install -g @rokkit/cli
rokkit <command>
```

## rokkit init / rokkit add

Interactive setup for an existing SvelteKit project. `rokkit add` is an alias. Run from the project root.

```bash
npx @rokkit/cli@latest init
npx @rokkit/cli@latest add   # same as init
```

### Flow

1. Detects SvelteKit project (checks for `svelte.config.js`)
2. Installs `@rokkit/ui`, `@rokkit/unocss`, `@rokkit/themes`, `@rokkit/icons` via detected package manager
3. Runs interactive prompts (see below)
4. Writes config files

### Prompts

| Prompt | Type | Description | Choices |
|--------|------|-------------|---------|
| `palette` | select | Color palette preset | `default` (orange/pink/sky), `vibrant` (blue/purple/sky), `seaweed` (sky/green/blue), `zen-sumi` (OKLCH ink-on-paper), `custom` |
| `primary` | text | Primary color (Tailwind name) | Default: `orange`. **Conditional:** only when `palette` is `custom` |
| `accent` | text | Accent color | Default: `sky`. **Conditional:** only when `palette` is `custom` |
| `surface` | text | Surface color | Default: `slate`. **Conditional:** only when `palette` is `custom` |
| `iconStyle` | select | Icon style variant | `Default (duotone)`, `Solid`, `Outline`, `Duotone outline` |
| `icons` | select | Icon collections | `rokkit` (Rokkit icons only), `custom` (Rokkit + custom collection) |
| `iconPath` | text | Path to custom icon collection JSON | Default: `./static/icons/custom.json`. **Conditional:** only when `icons` is `custom` |
| `themes` | multiselect | Theme styles | `rokkit` (default), `minimal`, `material`, `frosted`, `zen-sumi` |
| `defaultTheme` | select | Default theme style | **Conditional:** only when multiple themes selected |
| `switcher` | select | Theme switching mode | `system` (prefers-color-scheme), `manual` (light/dark toggle), `full` (light/dark + style variants) |
| `includeChart` | confirm | Include chart configuration? | Default: `true` |
| `chartColors` | select | Chart color set | `default` (14 colors), `warm` (8 colors), `cool` (8 colors). **Conditional:** only when chart included |
| `chartShades` | select | Chart shade contrast | `standard`, `high`, `soft`. **Conditional:** only when chart included |

### Files Written

| File | Notes |
|------|-------|
| `rokkit.config.js` | Colors, themes, switcher, storageKey, icons (with style), optional chart config. Skipped if exists. `storageKey` is derived from the project's `package.json` name (omitted if none). |
| `uno.config.js` | Written with `presetRokkit()` from `@rokkit/unocss`. Skipped if exists. |
| `src/app.css` | Prepends missing `@import` lines for `@unocss/reset/tailwind.css`, `@rokkit/themes/base.css`, and each selected theme. Creates if missing. |
| `src/app.html` | Injects flash-prevention `<script>` after `<body>`. Skipped when `switcher` is `system`, file doesn't exist, or script is already present. |

### After init

```
Done! Run `rokkit doctor` to verify your setup.
```

## rokkit doctor

Validates Rokkit project configuration. Run from the project root.

```bash
npx @rokkit/cli@latest doctor        # check only
npx @rokkit/cli@latest doctor --fix  # check and auto-fix where possible
```

### Checks

| ID | Description | Auto-fixable |
|----|-------------|-------------|
| `config-exists` | `rokkit.config.js` exists | Yes — generates an empty `export default {}` config file |
| `uno-uses-preset` | `uno.config.js` uses `presetRokkit()` | No — requires manual edit (see below) |
| `css-imports` | `src/app.css` has theme imports (`@rokkit/themes/base.css`) | Yes — prepends missing imports to `src/app.css` |
| `css-theme` | `src/app.css` imports at least one theme style (e.g. `@rokkit/themes/rokkit.css`) | No — advisory **warning**, not a failure; add a theme `@import` manually |
| `html-init-script` | `src/app.html` has theme init script (`rokkit-theme` / `data-mode`) | Yes — injects flash-prevention script after `<body>` tag |
| `chart-config` | `rokkit.config.js` has a `chart` section | Advisory **warning**, not a failure; fixable when `rokkit.config.js` exists |

### Exit codes

| Code | Meaning |
|------|---------|
| `0` | All checks passed |
| `1` | One or more checks failed |

### Manual fix: uno-uses-preset

`doctor --fix` will not overwrite an existing `uno.config.js`. Add `presetRokkit` manually:

```js
import { defineConfig } from 'unocss'
import { presetRokkit } from '@rokkit/unocss'

export default defineConfig({
  presets: [presetRokkit()]
})
```

## Icon Tools

For icon library authors only. Not required for standard Rokkit projects.

### rokkit bundle

Bundles SVG icons in the source folder into JSON files.

```bash
rokkit bundle [options]
rokkit bundle -i src -o build --config my-conf.json
```

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--config` | `-c` | `config.json` | Path to custom config file (resolved relative to the input folder) |
| `--input` | `-i` | `./src` | Source folder containing icon subfolders |
| `--output` | `-o` | `./lib` | Output folder for bundled JSON files |

### rokkit build

Builds a complete Iconify JSON package for each icon folder in the source directory.

```bash
rokkit build [options]
rokkit build -i src -o build --config my-conf.json
```

| Flag | Short | Default | Description |
|------|-------|---------|-------------|
| `--config` | `-c` | `config.json` | Path to custom config file (resolved relative to the input folder) |
| `--input` | `-i` | `./src` | Source folder containing icon subfolders |
| `--output` | `-o` | `./lib` | Output folder for built Iconify packages |

## rokkit upgrade

Checks for `@rokkit/*` package updates and optionally installs them.

```bash
rokkit upgrade          # check only
rokkit upgrade --apply  # install updates
```

Detects the package manager from lockfiles (bun, pnpm, yarn, npm) and runs the appropriate install command.

## rokkit skin list / rokkit skin create

Manage named skins in `rokkit.config.js`.

```bash
rokkit skin list              # list all skins defined in config
rokkit skin create --name ocean  # scaffold a new skin entry
```

## rokkit theme list / rokkit theme create

Manage themes.

```bash
rokkit theme list               # list built-in and custom themes
rokkit theme create --name corp # scaffold a new CSS theme stub
```

## rokkit skills

Manage bundled AI skill guides (SKILL.md files) for Claude Code and compatible AI assistants. Available since v1.1.13.

```bash
rokkit skills list              # list available bundled skills (marks already-installed ones)
rokkit skills add               # interactive multiselect — pick skills to install
rokkit skills add <name> [...]  # install one or more named skills by name
rokkit skills add --all         # install all available skills
rokkit skills add --force       # overwrite existing installed skills
```

Skills are copied into `.claude/skills/<name>/SKILL.md` in your project root.

| Flag | Description |
|------|-------------|
| `--all` | Install all available bundled skills |
| `--force` | Overwrite skills that are already installed |

```bash
# Example: check what's available, then install everything
npx @rokkit/cli@latest skills list
npx @rokkit/cli@latest skills add --all
```

Bundled skills: `semantic-styles-rokkit` (theming/tokens), `rokkit-components` (component usage), `command-system-rokkit` (shortcuts + palette), `skin-system-rokkit` (skins).

## rokkit agents

Manage bundled review agents (Claude-Code agent `.md` files) for Claude Code and compatible AI assistants. Available since v1.3.7.

```bash
rokkit agents list              # list available bundled agents (marks already-installed ones)
rokkit agents add               # interactive multiselect — pick agents to install
rokkit agents add <name> [...]  # install one or more named agents by name
rokkit agents add --all         # install all available agents
rokkit agents add --force       # overwrite existing installed agents
rokkit agents add <name> --remote  # pull from the site instead of the bundled copy
```

Agents are copied into `.claude/agents/<name>.md` in your project root.

| Flag | Description |
|------|-------------|
| `--all` | Install all available bundled agents |
| `--force` | Overwrite agents that are already installed |
| `--remote` | Fetch named agents from `https://rokkit.sensei-hq.com/agents/<name>.md` instead of the bundled copy |

Bundled agents (both review a *consuming* app — before coding, and verify after with a build + Playwright light/dark snapshots):
- `rokkit-styles-reviewer` — `rokkit.config.js` palette→skin→token wiring, named tokens vs raw hex/oklch, `shape`/`typography` config, dual-palette dark mode.
- `rokkit-components-reviewer` — steers to the simplest customization tier (data → `fields` → snippets), plus custom icons (UnoCSS `i-*` / `@rokkit/icons` vs literal-text/emoji field) and typography usage (`font-heading`/`font-body`/`font-mono`).

These agents, the skills above, and the `/llms` corpus are declared in `sensei.library.json` (repo root, also served at `/.well-known/sensei.library.json`) so tools like sensei can ingest and self-configure a rokkit-using project.
