# Rokkit InputCheckbox Component

> Accessible checkbox input with three visual states and customizable state icons.

> **`InputCheckbox` is a `@rokkit/forms` input.** It is normally rendered for you by a schema-driven [Form](/llms/components/form.txt) (`FormRenderer`), but it is also a plain Svelte component you can import and use standalone. Import it from `@rokkit/forms` — it is **not** exported from `@rokkit/ui`.

The InputCheckbox component provides a boolean toggle with three visual states: checked, unchecked, and unknown (`null`/`undefined`). It renders a native `<input type="checkbox">` for form state and, in the default `custom` variant, a styled icon span you can theme per state.

## Quick Start

```svelte
<script>
  import { InputCheckbox } from '@rokkit/forms'

  let accepted = $state(false)
</script>

<InputCheckbox name="terms" bind:value={accepted} />
<label>I accept the terms and conditions</label>
```

## Core Concepts

### Three States

InputCheckbox supports three visual states, driven by `value`:

```svelte
<script>
  import { InputCheckbox } from '@rokkit/forms'

  let checked = $state(true)      // Checked state
  let unchecked = $state(false)   // Unchecked state
  let unknown = $state(null)      // Unknown state (null or undefined)
</script>

<InputCheckbox bind:value={checked} />
<InputCheckbox bind:value={unchecked} />
<InputCheckbox bind:value={unknown} />
```

`null` and `undefined` both render the `unknown` icon. Any other value is coerced to a boolean for the native input's `checked` state.

### Variants

The `variant` prop selects how the checkbox is presented:

- `custom` (default) — the native `<input>` is hidden and a styled `[data-checkbox-icon]` span is shown. Toggled by click, `Enter`, or `Space`.
- `default` — the native `<input type="checkbox">` is rendered directly, with full native semantics.

```svelte
<InputCheckbox bind:value variant="default" />
<InputCheckbox bind:value variant="custom" />
```

### Custom State Icons

Override the icon class used for each state via the `icons` prop. Provided values are merged over the defaults, so you can override only the states you care about:

```svelte
<script>
  import { InputCheckbox } from '@rokkit/forms'

  const customIcons = {
    checked: 'fa-solid fa-square-check',
    unchecked: 'fa-regular fa-square',
    unknown: 'fa-solid fa-square-minus'
  }
</script>

<InputCheckbox icons={customIcons} bind:value />
```

### Disabled State

Set the native `disabled` attribute to prevent interaction:

```svelte
<InputCheckbox value={true} disabled />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `boolean \| null` | `undefined` | Checkbox state (use `bind:value`). `null`/`undefined` render the `unknown` icon |
| `variant` | `'default' \| 'custom'` | `'custom'` | `custom` shows the icon span (native input hidden); `default` renders the native checkbox |
| `icons` | `StateIcons` | `DEFAULT_STATE_ICONS.checkbox` | Icon class per state (`checked`/`unchecked`/`unknown`); merged over the defaults |
| `onchange` | `(value: boolean) => void` | `undefined` | Called with the new boolean when the checkbox is toggled |
| `name` | `string` | `undefined` | Native input `name` (form submission) |
| `id` | `string` | `undefined` | Native input `id` |
| `disabled` | `boolean` | `undefined` | Disables the input |
| `required` | `boolean` | `undefined` | Marks the input required |

Any other native input attribute (`onfocus`, `onblur`, `tabindex`, `class`, `aria-*`, …) is forwarded to the underlying `<input>` element.

### State Icons Object

Icon values are CSS class names applied to the visual icon span (in the `custom` variant):

```javascript
const icons = {
  checked: 'checkbox-checked',
  unchecked: 'checkbox-unchecked',
  unknown: 'checkbox-unknown'
}
```

Defaults come from `DEFAULT_STATE_ICONS.checkbox` in `@rokkit/core`:

- `checked`: `'checkbox-checked'`
- `unchecked`: `'checkbox-unchecked'`
- `unknown`: `'checkbox-unknown'`

## Component Structure

```
[data-checkbox-root][data-variant]
├── <input type="checkbox">      // Native input (hidden when variant="custom")
└── [data-checkbox-icon]         // Visual icon span (only when variant="custom")
```

## Data Attributes for Styling

| Attribute | Element | Purpose |
|-----------|---------|---------|
| `[data-checkbox-root]` | Root | Main container |
| `[data-checkbox-root][data-variant="custom"]` | Root | Custom icon variant |
| `[data-checkbox-root][data-variant="default"]` | Root | Native input variant |
| `[data-checkbox-icon]` | Icon | Custom visual icon span |

### Styling Example

```css
[data-checkbox-root] {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  cursor: pointer;
  user-select: none;
}

[data-checkbox-icon] {
  font-size: 1.25rem;
  color: var(--surface-600);
  transition: color 0.15s, transform 0.15s;
}

[data-checkbox-root]:has(input:checked) [data-checkbox-icon] {
  color: var(--primary-500);
}

[data-checkbox-root]:hover [data-checkbox-icon] {
  transform: scale(1.1);
}

[data-checkbox-root]:active [data-checkbox-icon] {
  transform: scale(0.95);
}

[data-checkbox-root]:has(input:disabled) {
  opacity: 0.5;
  cursor: not-allowed;
}

[data-checkbox-root]:has(input:disabled):hover [data-checkbox-icon] {
  transform: none;
}
```

## Keyboard Navigation

In the `custom` variant, the icon span is focusable (`tabindex="0"`) and responds to:

| Key | Action |
|-----|--------|
| `Enter` | Toggle checkbox |
| `Space` | Toggle checkbox |

In the `default` variant, the native checkbox provides standard browser keyboard behavior.

## Accessibility

- The native `<input type="checkbox">` carries the checkbox state and participates in form submission.
- In the `custom` variant the native input is hidden and the visual `[data-checkbox-icon]` span is `role="button"`, `tabindex="0"`, `aria-hidden="true"`, and toggles on click / `Enter` / `Space`. Pair it with a visible `<label>` for context.
- In the `default` variant the native checkbox is rendered directly, exposing full native semantics and keyboard support.
- `disabled` sets the native input's `disabled` attribute.

### Unknown / Indeterminate State

```svelte
<script>
  import { InputCheckbox } from '@rokkit/forms'

  let items = $state([
    { name: 'Item 1', checked: true },
    { name: 'Item 2', checked: false },
    { name: 'Item 3', checked: true }
  ])

  // Parent is unknown when some (not all) children are checked
  let allChecked = $derived.by(() => {
    const checkedCount = items.filter(i => i.checked).length
    if (checkedCount === 0) return false
    if (checkedCount === items.length) return true
    return null // Unknown → renders the unknown icon
  })

  function toggleAll() {
    const newValue = allChecked !== true
    items = items.map(i => ({ ...i, checked: newValue }))
  }
</script>

<div class="checkbox-field">
  <InputCheckbox value={allChecked} onchange={toggleAll} />
  <label>Select All</label>
</div>

{#each items as item, i}
  <div class="checkbox-field indent">
    <InputCheckbox bind:value={items[i].checked} />
    <label>{item.name}</label>
  </div>
{/each}
```

### Custom Icons

```svelte
<script>
  import { InputCheckbox } from '@rokkit/forms'

  let value = $state(false)

  // Heart-style checkbox
  const heartIcons = {
    checked: 'fa-solid fa-heart',
    unchecked: 'fa-regular fa-heart',
    unknown: 'fa-solid fa-heart-crack'
  }

  // Star-style checkbox
  const starIcons = {
    checked: 'fa-solid fa-star',
    unchecked: 'fa-regular fa-star',
    unknown: 'fa-solid fa-star-half-stroke'
  }
</script>

<InputCheckbox bind:value icons={heartIcons} />
<InputCheckbox bind:value icons={starIcons} />
```

### Form Integration

```svelte
<script>
  import { InputCheckbox } from '@rokkit/forms'

  let formData = $state({
    subscribe: false,
    terms: false
  })

  function handleSubmit() {
    console.log('Form data:', formData)
  }
</script>

<form onsubmit={handleSubmit}>
  <div class="checkbox-field">
    <InputCheckbox name="subscribe" bind:value={formData.subscribe} />
    <label>Subscribe to newsletter</label>
  </div>

  <div class="checkbox-field">
    <InputCheckbox name="terms" bind:value={formData.terms} />
    <label>I agree to the terms and conditions</label>
  </div>

  <button type="submit" disabled={!formData.terms}>
    Submit
  </button>
</form>
```

### Read-Only Display (disabled)

```svelte
<script>
  import { InputCheckbox } from '@rokkit/forms'

  const permissions = [
    { name: 'Read', granted: true },
    { name: 'Write', granted: true },
    { name: 'Delete', granted: false },
    { name: 'Admin', granted: false }
  ]
</script>

<h3>Your Permissions</h3>
{#each permissions as perm}
  <div class="checkbox-field">
    <InputCheckbox value={perm.granted} disabled />
    <label>{perm.name}</label>
  </div>
{/each}
```
