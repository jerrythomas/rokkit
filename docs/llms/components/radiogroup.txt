# Rokkit InputRadio Component

> Data-driven radio button group for single selection from a list of options.

> **`InputRadio` is a `@rokkit/forms` input.** It is normally rendered for you by a schema-driven [Form](/llms/components/form.txt) (`FormRenderer`), but it is also a plain Svelte component you can import and use standalone. Import it from `@rokkit/forms` — it is **not** exported from `@rokkit/ui`.

The InputRadio component renders a vertical list of native radio buttons that adapts to any data structure through field mapping. Each option is a native `<input type="radio">` wrapped in a `<label>`, so it inherits standard keyboard behavior and accessibility.

## Quick Start

```svelte
<script>
  import { InputRadio } from '@rokkit/forms'

  const options = ['Small', 'Medium', 'Large']
  let value = $state('Medium')
</script>

<InputRadio {options} bind:value />
```

## Core Concepts

### Data-Driven Design

InputRadio adapts to your data structure through field mapping. The `fields` prop is a plain `FieldMapping` object that tells the component which key holds each option's display label:

```svelte
<script>
  import { InputRadio } from '@rokkit/forms'

  const plans = [
    { id: 'basic', name: 'Basic Plan', price: 9 },
    { id: 'pro', name: 'Pro Plan', price: 29 },
    { id: 'enterprise', name: 'Enterprise', price: 99 }
  ]

  // `selected` holds the whole chosen plan object
  let selected = $state(plans[0])
</script>

<InputRadio options={plans} fields={{ label: 'name' }} bind:value={selected} />
```

### Value Binding

The bound `value` is the **whole selected option**, not a mapped value field. For a string array it is the selected string; for an object array it is the selected object. Selection is matched by deep equality, so bind `value` to an item from `options` (or a deep-equal copy).

### Field Mapping

Each option is wrapped in a `ProxyItem` (from `@rokkit/states`) using `fields`, and its display text is read from the `label` semantic key. The default mapping (`BASE_FIELDS` from `@rokkit/core`) maps `label` to the raw `label` key; override it with `fields` to point at a different property.

```svelte
<script>
  import { InputRadio } from '@rokkit/forms'

  // Simple string array — labels come from the strings themselves
  const sizes = ['S', 'M', 'L', 'XL']
  let size = $state('M')

  // Object array — map `label` to a custom property
  const colors = [
    { colorName: 'Red', hex: '#ff0000' },
    { colorName: 'Blue', hex: '#0000ff' }
  ]
  let color = $state(colors[0])
</script>

<InputRadio options={sizes} bind:value={size} />
<InputRadio options={colors} fields={{ label: 'colorName' }} bind:value={color} />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `options` | `unknown[]` | `[]` | Array of options (primitives or objects) |
| `value` | `unknown` | — | Selected option — the whole item (use `bind:value`) |
| `fields` | `FieldMapping` | `BASE_FIELDS` | Field mapping used to resolve each option's display label |
| `disabled` | `boolean` | `false` | Disables every radio input |
| `flip` | `boolean` | — | Declared in the props type (reserved for label/control order) |
| `onchange` | `(value: unknown) => void` | `noop` | Called with the newly selected item |
| `class` | `string` | `''` | CSS class applied to the `<radio-group>` element |

`onfocus` and `onblur` handlers, plus any other extra attributes, are forwarded to each native radio input.

## Field Mapping

The display label for each option is resolved through the `label` key of `fields`:

| Semantic key | Default raw key | Used for |
|--------------|-----------------|----------|
| `label` | `'label'` | Display text for each option |

For primitive options (strings, numbers), the value is used directly as both the label and the value, so no mapping is needed. Note again that the **bound `value` is always the full option**, regardless of `fields`.

## Keyboard Navigation

Uses native HTML radio button behavior:

| Key | Action |
|-----|--------|
| `ArrowUp` | Previous option |
| `ArrowDown` | Next option |
| `ArrowLeft` | Previous option |
| `ArrowRight` | Next option |
| `Space` | Select focused option |
| `Tab` | Move focus in/out of group |

## Disabled State

Disable interaction for the whole group with the `disabled` prop:

```svelte
<InputRadio {options} bind:value disabled />
```

When `disabled` is true, every radio input receives the native `disabled` attribute and the `<radio-group>` element gets a `disabled` class.

## Accessibility

- Uses native `<input type="radio">` elements.
- Grouping is handled by Svelte's `bind:group` (the component does not set a `name` attribute).
- Each option is wrapped in a `<label>` so the text is part of the click target.
- `disabled` applies the native `disabled` attribute to every input.

## Data Attributes for Styling

The component renders a custom `<radio-group>` element; style it with element/class selectors:

| Element | Selector | Description |
|---------|----------|-------------|
| Root | `radio-group` | Custom-element container |
| Disabled root | `radio-group.disabled` | Applied when `disabled` is true |
| Option | `radio-group label` | Individual radio option |
| Input | `radio-group input[type="radio"]` | Native radio input |
| Text | `radio-group p` | Label text |

### Styling Example

```css
radio-group {
  display: flex;
  flex-direction: column;
  gap: 8px;
}

radio-group label {
  display: flex;
  align-items: center;
  gap: 8px;
  cursor: pointer;
  padding: 8px 12px;
  border-radius: 6px;
  transition: background-color 0.15s;

  background-color: var(--surface-100);
}

  opacity: 0.5;
  cursor: not-allowed;
}

  margin: 0;
  font-size: 0.875rem;
}
```

## Import

```javascript
import { InputRadio } from '@rokkit/forms'

// FieldMapping type (for typing custom mappings)
import type { FieldMapping } from '@rokkit/core'
```

## TypeScript Types

```typescript
import type { FieldMapping } from '@rokkit/core'

interface InputRadioProps {
  class?: string
  value?: unknown
  fields?: FieldMapping
  options?: unknown[]
  disabled?: boolean
  flip?: boolean
  onchange?: (value: unknown) => void
  onfocus?: (event: FocusEvent) => void
  onblur?: (event: FocusEvent) => void
  [key: string]: unknown
}
```

## Examples

### Simple String Options

```svelte
<script>
  import { InputRadio } from '@rokkit/forms'

  let priority = $state('medium')
</script>

<InputRadio
  options={['low', 'medium', 'high', 'urgent']}
  bind:value={priority}
/>
```

### Object Options with Field Mapping

```svelte
<script>
  import { InputRadio } from '@rokkit/forms'

  const shippingOptions = [
    { method: 'standard', label: 'Standard (5-7 days)', cost: 0 },
    { method: 'express', label: 'Express (2-3 days)', cost: 9.99 },
    { method: 'overnight', label: 'Overnight', cost: 24.99 }
  ]

  // `label` is already the display key, so no custom mapping is needed here.
  // `shipping` holds the whole selected option object.
  let shipping = $state(shippingOptions[0])
</script>

<InputRadio
  options={shippingOptions}
  bind:value={shipping}
/>
```

### Custom Label Field

```svelte
<script>
  import { InputRadio } from '@rokkit/forms'

  const users = [
    { userId: 1, fullName: 'Ada Lovelace' },
    { userId: 2, fullName: 'Alan Turing' }
  ]

  let assignee = $state(users[0])
</script>

<InputRadio
  options={users}
  fields={{ label: 'fullName' }}
  bind:value={assignee}
/>
```

### Disabled Group

```svelte
<script>
  import { InputRadio } from '@rokkit/forms'

  let savedChoice = $state('Option B')
</script>

<InputRadio
  options={['Option A', 'Option B', 'Option C']}
  bind:value={savedChoice}
  disabled
/>
```

### Form Integration

```svelte
<script>
  import { InputRadio } from '@rokkit/forms'

  let formData = $state({ size: 'M' })

  function handleSubmit() {
    console.log('Form data:', formData)
  }
</script>

<form onsubmit={handleSubmit}>
  <fieldset>
    <legend>Select Size</legend>
    <InputRadio
      options={['XS', 'S', 'M', 'L', 'XL']}
      bind:value={formData.size}
    />
  </fieldset>
  <button type="submit">Submit</button>
</form>
```
