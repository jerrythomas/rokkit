# PlotChart

Low-level declarative chart container. Compose charts by placing geom components as children, or pass a `spec` object for the spec-driven API.

## Import

```javascript
import { PlotChart, GeomBar, GeomLine, GeomArea, GeomPoint, GeomArc, GeomBox, GeomViolin } from '@rokkit/chart'
```

## Quick Start

```svelte
<!-- Component-based composition -->
<PlotChart {data} width={600} height={400}>
  <GeomBar x="category" y="revenue" color="region" stat="mean" />
</PlotChart>

<!-- Spec-driven (same result) -->
<PlotChart spec={{
  data: rows,
  x: 'category', y: 'revenue', color: 'region',
  geoms: [{ type: 'bar', stat: 'mean' }]
}} />
```

## PlotChart Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `Object[]` | `[]` | Data rows |
| `spec` | `PlotSpec` | — | Spec object (alternative to child geoms + individual props) |
| `helpers` | `PlotHelpers` | `{}` | Crossfilter / brewer helpers |
| `width` | `number` | `600` | SVG width in pixels |
| `height` | `number` | `400` | SVG height in pixels |
| `mode` | `'light' \| 'dark'` | `'light'` | Palette mode |
| `grid` | `boolean` | `true` | Show gridlines |
| `axes` | `boolean` | `true` | Show axes |
| `margin` | `object` | `{top:20,right:20,bottom:40,left:50}` | Margin override |
| `legend` | `boolean` | `false` | Show legend |
| `title` | `string` | `''` | Chart title |
| `tooltip` | `boolean \| (d) => string` | `false` | Hover tooltip |
| `xDomain` | `unknown[]` | inferred | Fix the x domain instead of inferring it — e.g. `[0, 1]` for a plane defined by theory. `spec.xDomain` wins |
| `yDomain` | `unknown[]` | inferred | Fix the y domain |

## Geom Props

The `Geom*` exports are equivalent to the `Plot.*` namespace members (`GeomBar` === `Plot.Bar`) — use either.

All geoms accept `stat` (`identity` | `sum` | `mean` | `min` | `max` | `count`) and `alpha` (fixed opacity 0–1). Any `fill`/`color` channel also accepts a literal colour — `var(--token)`, `oklch(…)`, `#hex`, `currentColor` — painted directly instead of mapping a field.

**GeomBar**: `x`, `y`, `fill`, `color`, `pattern`, `group`, `position` (`dodge` (default) | `stack` | `fill` | `identity`), `alpha`, `label`, `filterable`, `options.orientation` (`vertical` (default) | `horizontal`). (`options.stack: true` is a deprecated alias for `position="stack"`.)

**GeomLine**: `x`, `y`, `color`, `symbol`, `alpha`, `label`, `options.curve`, `options.strokeWidth`

**GeomPoint**: `x`, `y`, `color`, `size`, `symbol`, `alpha`, `label`, `options.radius`

**GeomArc**: `theta`, `fill` (or `color`), `pattern`, `alpha`, `labelFn`, `options.innerRadius`

**GeomArea**: `x`, `y`, `fill`, `color`, `pattern`, `group`, `position` (`stack` | `fill` | `identity`), `alpha`

**GeomBox** / **GeomViolin**: `x`, `y`, `fill`, `color`, `pattern`, `alpha`

**GeomRule**: `x`, `y` (value or array), `slope`, `intercept` (default 0), `label`, `color`, `dash`, `strokeWidth`. A sloped line is clipped to the visible domain and labelled at its midpoint along the line.

**GeomRegion**: `x`, `y` (`[lo, hi]`; `null` runs to the axis edge), `points` (polygon, wins over ranges), `name` (→ `data-plot-region`), `label`, `labelAt`, `fill`, `alpha`, `stroke`. Reads no data and never moves the scales; clipped to the plot area. Place before the marks it sits behind.

**GeomHull**: `x`, `y`, `fill` / `color` (the group field), `padding` (px), `alpha`, `label`. One convex hull per group, padded clear of its points.

**GeomContour**: `x`, `y`, `fill` / `color` (group), `bandwidth` (px), `thresholds`, `filled`, `alpha`. Kernel-density contours, clipped to the plot area.

## Spec-driven API

```svelte
<PlotChart spec={{
  data: rows,
  width: 600,
  height: 400,
  x: 'month',
  y: 'revenue',
  color: 'region',
  geoms: [{ type: 'bar', stat: 'sum' }, { type: 'line' }]
}} />
```

## CrossFilter integration

```svelte
<CrossFilter>
  <PlotChart {data}>
    <GeomBar x="category" y="revenue" filterable />
  </PlotChart>
</CrossFilter>
```

Geoms with `filterable` dim or hide unselected data when a filter is active.
