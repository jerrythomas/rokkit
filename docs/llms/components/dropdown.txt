# Rokkit Dropdown Component

> Trigger button whose label reflects the currently selected value, plus a panel of options.

Dropdown sits between Menu and Select. Like Menu it is an option panel hung off a
trigger; unlike Menu, the trigger shows the **current selection** rather than a
static label. Unlike Select it is not a form-style control — there is no filter,
no `selected` raw-item binding, and no snippet customisation of the options.

Reach for it when you want a compact "current value + choices" control, such as a
view switcher or a sort order.

## Quick Start

```svelte
<script>
  import { Dropdown } from '@rokkit/ui'

  const items = [
    { text: 'Newest first', value: 'desc' },
    { text: 'Oldest first', value: 'asc' }
  ]
  let value = $state('desc')
</script>

<Dropdown {items} bind:value placeholder="Sort by" />
```

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `unknown[]` | `[]` | Data array (objects or primitives) |
| `fields` | `Record<string,string>` | `{}` | Remap data keys to component fields |
| `value` | `unknown` | — | Selected value — use `bind:value` |
| `placeholder` | `string` | `'Select an option'` | Trigger text when nothing is selected |
| `icon` | `string` | — | Icon class rendered in the trigger |
| `size` | `string` | `'md'` | Size variant (`sm` \| `md` \| `lg`) |
| `disabled` | `boolean` | `false` | Disable the dropdown |
| `showArrow` | `boolean` | `true` | Show the expand/collapse chevron |
| `align` | `'start'\|'end'` | `'start'` | Panel alignment relative to trigger |
| `direction` | `'up'\|'down'` | `'down'` | Panel direction |
| `icons` | `{ opened?, closed? }` | — | Override the chevron icons |
| `onchange` | `(value, item) => void` | — | Called on selection |
| `class` | `string` | `''` | Additional CSS classes on root `<div>` |

**No snippet props.** Dropdown renders options with the built-in item content
only. If you need custom option markup, use [Menu](/llms/components/menu.txt) or
[Select](/llms/components/select.txt), both of which accept `itemContent` and
`groupContent`.

## Field mapping

Dropdown uses the standard `BASE_FIELDS` mapping — `text`, `value`, `icon`,
`description`, and so on. Remap with `fields`:

```svelte
<Dropdown items={rows} fields={{ text: 'label', value: 'id' }} bind:value />
```

## Theming

### Data attributes

| Attribute | Element |
|---|---|
| `data-dropdown` | root `<div>` (also carries `data-open`, `data-size`, `data-align`, `data-direction`) |
| `data-dropdown-trigger` | trigger `<button>` |
| `data-dropdown-icon` | optional icon span in the trigger |
| `data-dropdown-label` | selected-value text in the trigger |
| `data-dropdown-arrow` | expand/collapse chevron |
| `data-dropdown-panel` | options panel |
| `data-dropdown-option` | each option item |
| `data-dropdown-separator` | separator between options |
| `data-active` | marks the currently selected option |

### Styling via the `class` prop

```svelte
<Dropdown {items} bind:value class="[&[data-open]]:shadow-lg" />
```

## Keyboard navigation

| Key | Action |
|-----|--------|
| `Enter` / `Space` | Open the panel (or select the focused option) |
| `ArrowDown` / `ArrowUp` | Move between options |
| `Home` / `End` | First / last option |
| `Escape` | Close the panel |
| `Tab` | Close and move focus on |

## TypeScript Types

```typescript
import type { DropdownProps } from '@rokkit/ui'

interface DropdownProps extends SelectBaseProps {
  value?: unknown
  icon?: string
  showArrow?: boolean
  onchange?: (value: unknown, item: unknown) => void
}
```

`Dropdown.svelte` annotates its own `$props()` with `DropdownProps`, so this
table and the component cannot drift.

## Import

```svelte
import { Dropdown } from '@rokkit/ui'
```
